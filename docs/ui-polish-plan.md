# UI 精修方案 · fitness-app

> 主题：把 App 从"学习项目"打磨成"像真的产品级健身 App"。
> 方式：**你动手实施，我每步指导**。每步一个小改动，做完就能在预览看到效果。
> 进度：做完一步就把 `[ ]` 改成 `[x]`。

---

## [ ] Step 1 · 统一三个页面的标题
- **现状**：TodayTab 标题 `text-[34px]`，Record/History 是 `text-[28px]`，大小不一致；Record/History 标题没居中。
- **改**：三个页面 `<h1>` 都统一成 `text-[28px] text-center`。
- **文件**：`src/tabs/TodayTab.tsx`、`RecordTab.tsx`、`HistoryTab.tsx`
- **效果**：标题风格一致 → 有产品感。

## [ ] Step 2 · 升级底部导航（加图标 + 选中指示）
- **现状**：底部只有文字"今天 / 记录 / 历史"。
- **改**：每个 tab 顶部加 emoji（🏠 / ✍️ / 📅）；选中的 tab 文字下方加一个小圆点。
- **文件**：`src/App.tsx`（`TabButton` 组件）
- **效果**：导航更直观、更专业。

## [ ] Step 3 · 连续天数卡加"本周打卡点"（招牌视觉）
- **现状**：只显示一个大数字。
- **改**：数字下方加一排 7 个小圆点（周一~周日），有训练的日子填强调色，没有的空心。
- **文件**：`src/tabs/TodayTab.tsx` + `src/lib/streak.ts`（加一个 `weekStatus(workouts)` 函数）
- **效果**：一眼看到本周节奏——这是健身 App 的经典视觉。
- **注**：这步稍难（要算本周），我会把现成函数给你，你负责接上去。

## [ ] Step 4 · 统一按钮和输入框风格
- **现状**：RecordTab 输入框圆角/聚焦样式不统一。
- **改**：输入框统一 `rounded-xl` + 聚焦时边框用强调色；按钮圆角和按压反馈统一。
- **文件**：`src/tabs/RecordTab.tsx`（对照 TodayTab 按钮保持一致）
- **效果**：表单更精致、更顺手。

## [ ] Step 5 · 历史卡片精修
- **现状**：历史卡的日期是普通文字。
- **改**：日期用 `font-display`（衬线）；加个小标签显示"共 N 个动作"。
- **文件**：`src/tabs/HistoryTab.tsx`
- **效果**：历史页信息更清楚、更有质感。
